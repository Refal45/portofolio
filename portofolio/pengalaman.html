Pengalaman paling berharga adalah memahami perbedaan cara eksekusi query pada aplikasi web: bind parameter (prepared statement) vs get result (query langsung). Dalam konteks cPanel dan pengembangan web, menggunakan bindParam (PDO PHP) memberikan keamanan tinggi terhadap SQL injection.

Catatan Teknis: Di cPanel saya mengimplementasikan prepared statement dengan bindParam. Perbedaan utama: bindParam mengikat parameter secara aman; sedangkan get_result() (MySQLi) mengambil hasil setelah eksekusi prepared statement, namun tetap harus menggunakan parameter binding.

Bind Parameter vs Get Result (cPanel & PHP)

MetodeDeskripsiKeamanan SQL Injection
bindParam (PDO / MySQLi Prepared)Mengikat parameter ke statement sebelum eksekusi. Query dan data terpisah. Sangat aman
getResult (MySQLi → get_result())Mengambil hasil set setelah prepared statement dieksekusi. Aman jika pakai bind_param
Query langsung (tanpa binding)Menggabungkan variabel ke SQL mentah. Rawan SQL injection
Praktik terbaik di cPanel: Selalu gunakan prepared statement. Contoh PDO: 
$stmt = $pdo->prepare("SELECT * FROM products WHERE category = :cat");
$stmt->bindParam(':cat', $category, PDO::PARAM_STR);
$stmt->execute();
$results = $stmt->fetchAll();
Manajemen File & Direktori di cPanel
  • Upload dan ekstrak file website via File Manager atau FTP.
  • Mengatur permission folder (755 untuk direktori, 644 untuk file).
  • Mengelola file .htaccess untuk pengalihan dan keamanan.
  • Membuat subdomain dan addon domain untuk staging.
