Pengalaman paling berharga adalah memahami perbedaan cara eksekusi query pada aplikasi web: bind parameter (prepared statement) vs get result (query langsung). Dalam konteks cPanel dan pengembangan web, menggunakan bindParam (seperti pada PDO PHP) memberikan keamanan tinggi terhadap SQL injection karena memisahkan logika query dari data. Sementara getResult atau eksekusi langsung rentan terhadap serangan jika input tidak disaring.

Catatan Teknis: Di cPanel saya mengimplementasikan koneksi database MySQL dengan prepared statement (bindParam) untuk aplikasi internal. Perbedaan utama: bindParam mengikat parameter secara aman, eksekusi terpisah; sedangkan get_result() (pada MySQLi) mengambil hasil setelah eksekusi, namun tetap harus menggunakan parameter binding. Pada proyek portfolio ini, saya lebih memilih pendekatan binding untuk keamanan dan performa.

Bind Parameter vs Get Result (cPanel & PHP)

Saat bekerja di lingkungan hosting cPanel dengan database MySQL, salah satu aspek krusial adalah bagaimana kita berinteraksi dengan database. Berikut perbandingan yang saya pelajari:

Metode Deskripsi Keamanan SQL Injection
bindParam (PDO / MySQLi Prepared) Mengikat parameter ke statement sebelum eksekusi. Query dan data dikirim terpisah. Sangat aman, karena input tidak dieksekusi sebagai query.
getResult (MySQLi -> get_result()) Mengambil hasil set setelah statement dieksekusi. Namun tetap harus menggunakan prepared statement sebelumnya. Aman jika dikombinasikan dengan bind_param, tapi raw query tanpa bind sangat berbahaya.
Query langsung (tanpa binding) Menggabungkan variabel langsung ke perintah SQL (contoh: "SELECT * FROM users WHERE id = $_GET[id]") Rawan SQL injection, tidak direkomendasikan.
Praktik terbaik di cPanel: Selalu gunakan bindParam (PDO) atau bind_param (MySQLi) untuk memproteksi data dari user.
Contoh implementasi di project UMKMSerangJuara: 
$stmt = $pdo->prepare("SELECT * FROM products WHERE category = :cat");
$stmt->bindParam(':cat', $category, PDO::PARAM_STR);
$stmt->execute();
$results = $stmt->fetchAll();
Dengan metode bindParam, parameter kategori aman meskipun berisi karakter spesial. getResult digunakan setelah eksekusi prepared statement untuk mengambil data, namun bukan alternatif dari binding.
Manajemen File & Direktori di cPanel

Selama PKL, saya diberikan akses ke akun cPanel untuk mengelola file, folder, serta hak akses. Beberapa kegiatan rutin:

  • Upload dan ekstrak file website menggunakan File Manager atau FTP.
  • Mengatur permission folder (755 untuk direktori, 644 untuk file).
  • Mengelola file .htaccess untuk pengalihan dan aturan keamanan.
  • Membuat subdomain dan addon domain untuk lingkungan staging.
  • Backup & restore langsung dari cPanel untuk menjaga ketersediaan data.
